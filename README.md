# ERM Запад (ЧЕЗ) Прекъсвания — Home Assistant integration

Неофициална интеграция за Home Assistant, която следи [info.ermzapad.bg](https://info.ermzapad.bg/webint/vok/avplan.php) — официалната справка на **ЕРМ Запад** (бивш ЧЕЗ Разпределение) — за прекъсвания на електрозахранването за вашата **точка на измерване (ITN)**.

Проверява два типа събития:

- **Планирани прекъсвания** — обявените ремонти за следващите **48 часа**
- **Текущи прекъсвания** — регистрирано планирано или непланирано прекъсване в момента

## Функции

- UI конфигурация (config flow) — въвеждате номера на точката си на измерване, без редакция на YAML
- 2 текстови сензора с подробния текст от ЕРМ Запад + атрибути `begin` / `end` (кога са извлечени дати)
- 2 binary сензора (`problem`): ON = има прекъсване → идеални за автоматизации
- Настройваеми интервали на проверка (планирани / текущи)
- Blueprint за автоматизация, която праща известия при обявено прекъсване и при възстановяване
- Без външни зависимости (само стандартната библиотека на Python)

## Инсталация (HACS)

1. HACS → ⋮ (горен десен ъгъл) → **Custom repositories**
2. URL: `https://github.com/bsmiho/ha-ermzapad-outages`
3. Category: **Integration** → Add
4. HACS → Integrations → **ERM Запад (ЧЕЗ) Прекъсвания** → **Download**
5. Рестартирайте Home Assistant

> Алтернативно: копирайте `custom_components/erm_zapad/` в директорията `custom_components/` на вашия HA и рестартирайте.

## Настройка

1. **Настройки → Устройства и услуги → Добавяне на интеграция**
2. Потърсете **ERM Запад (ЧЕЗ) Прекъсвания**
3. Въведете **точката на измерване (ITN)** от сметката за ток (12 или 16 символа)
4. (По желание) задайте интервали на проверка

Създадени обекти:

| Entity | Тип | Какво показва |
|---|---|---|
| `sensor.erm_zapad_planned_outage` | sensor | Текст: „Няма прекъсване“ или съобщението от ЕРМ Запад |
| `sensor.erm_zapad_current_outage` | sensor | Текст: „Няма прекъсване“ или съобщението от ЕРМ Запад |
| `binary_sensor.erm_zapad_planned_outage_flag` | binary_sensor | ON = има обявено планирано прекъсване |
| `binary_sensor.erm_zapad_current_outage_flag` | binary_sensor | ON = има текущо прекъсване |

## Уведомления (blueprint)

**Настройки → Автоматизации → Създай автоматизация → Използвай blueprint → „ERM Запад — уведомление при прекъсване на тока“**, изберете двата binary сензора и устройствата (телефони), които да получават известия — за вас и семейството.

Или ръчно:

```yaml
alias: "ERM Запад — сигнал за прекъсване"
triggers:
  - trigger: state
    entity_id:
      - binary_sensor.erm_zapad_planned_outage_flag
      - binary_sensor.erm_zapad_current_outage_flag
    to: "on"
conditions: []
actions:
  - action: notify.mobile_app_your_phone   # ← вашите устройства
    data:
      title: "⚡ Прекъсване на тока"
      message: "{{ state_attr('binary_sensor.erm_zapad_planned_outage_flag', 'details') }}"
mode: single
```

## Бележки

- Планираните прекъсвания се публикуват от ЕРМ Запад за прозорец от **48 часа** — с проверка няколко пъти на ден (по подразбиране ~на всеки 6 часа) няма да изпуснете обява.
- Ако токът реално спре, Home Assistant (и интеграцията) няма как да извести, докато не се върне захранването — затова планираните обяви са основният сценарий.
- Тази интеграция **не е официална** и не е свързана с ЕРМ Запад / Electrohold. Ползва публичната справка на сайта им; форматът може да се промени по всяко време.
- Вашият номер на точка на измерване се съхранява **само локално** в конфигурацията на Home Assistant.
